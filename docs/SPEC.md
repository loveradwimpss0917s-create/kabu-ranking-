# 株ランキングアプリ 仕様（v1試作）

作成: 2026-11-06（日経平均 -5.27%、東証プライム値下がり9割超の全面安の日）

## 目的
アプリを開いたら、その日の「候補ランキング」が理由つきで出る。
「買うべき」と断言するのではなく、チャート形状・指標・出来高をスコア化した
スクリーニングとして表示し、根拠とリスクと無効条件を必ず併記する。

※ kasoutuka の原則（検証されていない方向予測を推奨として出さない）を株アプリにも適用する。
　スコアは検証済みの予測モデルではないことを画面に明記する。

## 市況レジーム（先に市況を判定してからランキングの意味を変える）
- 全面安モード: 日経平均 -3%以下（または下落銘柄8割超）
  → ランキングは「反発候補（監視）」。上位でも一括の買い推奨にしない。
    各候補に無効条件（終値で直近安値を更新したら候補から外す）を併記。
- 軟調モード: -1%〜-3%
- 通常モード: それ以外 → 「今日の注目ランキング」

## スコア（100点）
| 配点 | 項目 | 中身 |
|---|---|---|
| 25 | 相対強さ | 当日の指数との差、20日の相対推移。指数ほど下げていない銘柄を評価 |
| 20 | 売られ過ぎ | RSI(14)、25日線乖離。RSI 28〜45・乖離 -12〜-3% が加点帯。RSI 20未満は「落下中」として減点 |
| 20 | 反転サイン | 下ヒゲ比率、当日レンジでの終値位置、陽線、直近安値更新＋弱い引けは減点 |
| 15 | トレンド健全性 | 75日線との位置、25日線>75日線、6か月高値からの下落率（-35%超は崩壊圏で減点） |
| 10 | 流動性・リスク | 売買代金、ATR%（荒すぎる銘柄は減点） |
| 10 | 下げ止まり | 20日騰落に対する5日騰落の鈍化、出来高を伴う下げ止まり |

## 目標価格（2026-11-06 追加、本人の要望）
各銘柄に購入目標・利確目標・損切りを表示する。いずれも予測ではなく、
ATR(14) から機械的に算出する「目安」として、算出式を画面にも併記する。
- 購入目標 E = 現在値 − 0.5×ATR（押し目で拾う想定の価格）
- 損切り S = E − 1.0×ATR（終値がこの価格以下で確定したら撤退）
- 利確目標 T = E + 2.0×ATR。ただし25日線がその手前にある場合は25日線を目標にする
  （売られ過ぎの反発では移動平均への回帰が現実的な到達点のため）。根拠（ATR×2.0 / 25日線）を表示
- リスクリワード比 (T−E)/(E−S)、想定リスク%・リワード% を併記
- 価格は呼び値の刻みに丸めた概算（TOPIX100等の細かい刻みは未対応）

## 注意フラグ（2026-11-06 追加、検証に基づく損失回避の表示）
ランキング順位（スコア）には影響させない。過去データの検証で「市場平均を
有意に下回る」と実測された群に、根拠つきの警告を表示するだけの機能である。
検証の詳細は ~/workspace/kabu-research/research/（2016-08〜2024-07、全銘柄・
事前登録制で実施。いずれもイン・サンプルの結果であり将来の再現は未確認）。

- **ストップ高で引け**: 直近営業日が終値ストップ高だった銘柄。
  検証001（イベント10,964件）: 翌日始値で買うと5日で市場平均比 −2.94%
  （コスト差引後、95%CI は 0 を大きく下回る）。翌日の追いかけ買いへの警告。
- **日中主導型**: 直近6か月の（日中リターン累積 − 夜間リターン累積）が
  全銘柄の上位20%に入る銘柄。検証005: この群は市場平均を −0.026%/日
  （年率換算 約 −6%）下回り、3つのサブ期間すべてで有意にマイナスだった。
  なお、この群を除外する売買戦略は検証008・009で実装を試したが成立しなかった
  （月次リバランスはコスト負け、12か月保有は効果が薄まる）。したがって
  本フラグは「買わない理由」ではなく「慎重に材料を確認する理由」として表示する。

## データ
- Yahoo Finance chart API（キー不要）で日足6か月分を取得し、Python標準ライブラリのみで計算。
  実測（2026-11-06）: この環境からは取得可。Stooq は bot 判定で取得不可だった。
- データ品質ガード（試作で実際に踏んだ教訓）:
  1. 陳腐化チェック: 銘柄の最終バーの日付が指数と違う場合はランキングから除外して明示する
     （実例: JT は当日のバーが未配信で、前日の +5.2% が「今日」として混入しかけた）。
  2. 急変は除外しない: ±10%超の値動きは「材料確認フラグ」として併記するに留める
     （実例: トヨタの 2026-11-05 +16.7% は異常値に見えたが、決算上方修正＋自社株買いによる実在の値動きだった）。
- 本実装の課題: GitHub Actions（米国ランナー）から Yahoo へ取得できるかの実機確認。
  kasoutuka では Bybit が米国ランナーから 403 になった前例がある。失敗する場合は
  取得を自前環境の定期実行＋コミット方式に切り替える。

## 構成（GitHub）
- `scripts/fetch_and_score.py` … 取得とスコア計算、`data/ranking.json` を出力
- `index.html` … 静的画面（ranking.json を読んで描画、スマホ前提）
- `.github/workflows/update.yml` … 平日朝7:00 JST（前日終値ベースで「今日の候補」）と
  15:45 JST（当日終値で更新）に自動実行してコミット、GitHub Pages で公開
- 対象ユニバース: 日経225全銘柄（2026-11-06 本人決定）。銘柄リストは実行時に
  日経公式CSV（株価換算係数一覧、対象日付つき）から取得するので、定期入替にも自動追随する。
  公式CSVに著作権表示があるため、リスト自体はリポジトリに複製しない。
