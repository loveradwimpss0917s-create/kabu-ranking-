# 株ランキング

アプリを開くと、その日の候補ランキングがスコアの内訳・根拠・リスクつきで表示される
日本株スクリーニングアプリ。対象は日経225全銘柄（銘柄リストは実行時に日経公式CSVから取得）。
仕様は `docs/SPEC.md`。

## 動かし方（ローカル試作）
```bash
python3 scripts/fetch_and_score.py data/ranking.json   # 取得とスコア計算
python3 -m http.server 8000                            # http://localhost:8000 で表示
```

## 注意
- ランキングはテクニカル指標に基づくスクリーニングであり、利益を保証する買い推奨ではありません。
- データは Yahoo Finance の非公式 API に依存します。陳腐化・急変のチェックは
  スクリプト側で行いますが、最終判断の前に一次情報での確認が必要です。
